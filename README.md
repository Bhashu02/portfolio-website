# Bhaswar Ghosh — Portfolio Website

A clean, minimal, and professional developer portfolio website showcasing IT & Digital Platforms Development work, modern web applications, and enterprise SharePoint/Power Platform solutions.

---

## 🚀 Quick Start (Local Preview)

This portfolio is built with standard, semantic HTML5, modern CSS3, and lightweight vanilla JavaScript. There are zero build steps, zero node dependencies, and nothing to install.

### Method 1: Python Local Server (Recommended)

Run the following command from the project root directory:

```bash
python3 -m http.server 8000
```

Then open your browser and navigate to:
[http://localhost:8000](http://localhost:8000)

### Method 2: Direct File Opening

You can also directly double-click `index.html` or run:

```bash
open index.html
```

## 🎨 Design System

- **Background:** Warm off-white (`#faf9f6` / `#f4f2ec`).
- **Text:** High-contrast neutral dark (`#18181b` headings, `#4b5563` body text) compliant with WCAG AAA contrast ratios.
- **Accent Color:** Deep refined teal (`#0f766e` with `#ccfbf1` subtle tints).
- **Typography:** Modern native system font stack with comfortable line height (1.65–1.7) and generous whitespace.
- **Visuals:** Large, proportion-preserving project cards (16:10 aspect ratio) with subtle hover elevations.
- **Accessibility:** Visible focus rings (`:focus-visible`), skip navigation link, semantic landmarks (`<header>`, `<nav>`, `<main>`, `<section>`, `<article>`, `<footer>`), and `prefers-reduced-motion` compliance.
